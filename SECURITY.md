# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

Please report security issues privately to **hello.medhira@gmail.com**.

Include:

- A description of the issue and impact
- Steps to reproduce
- Affected versions

We aim to acknowledge reports within 5 business days.
